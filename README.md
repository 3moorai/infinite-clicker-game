# لعبة النقر اللانهائية 🎮 | Infinite Clicker Game

لعبة نقر ممتعة وخفيفة باللغة العربية مبنية بالكامل باستخدام **HTML5, CSS3, JavaScript** النقي (Vanilla JS) بدون أي مكتبات خارجية.

---

## 🌟 المميزات (Features)

- 📷 **رفع صورة مخصصة:** إمكانية رفع صورتك أو أي صورة تفضلها لتكون هي زر النقر الرئيسي.
- 🛒 **متجر ترقيات لا نهائي:** شراء ترقيات لقوة النقرة ونقر تلقائي (CPS)، وتوليد عناصر جديدة باستمرار كلما تقدمت.
- 🏆 **نظام أوسمة ديناميكي:** إشعارات وإنجازات ومستويات تتحدث تلقائياً مع زيادة نقاطك ونقراتك.
- 🌙 **وضع داكن / فاتح:** تبديل سهل وسلس بين الثيم الليلي والنهاري.
- ✨ **تأثيرات بصرية جذابة:** أرقام متطايرة تفاعلية، انيميشن سلس، وتصميم مريح للعين.
- 📱 **تصميم متجاوب:** يعمل بكفاءة وسلاسة على جميع أحجام الشاشات.

---

## 🚀 طريقة التشغيل (How to Play)

1. حمّل المستودع أو استنسخه:
   ```bash
   git clone https://github.com/3moorai/infinite-clicker-game.git
   ```
2. افتح ملف `index.html` في أي متصفح ويب مباشرة.
